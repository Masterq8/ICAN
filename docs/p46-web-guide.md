# P4.6/P5 本地科研工作台使用说明

## 入口与语料范围

按 [README](../README.md) 安装前端依赖、构建并启动 FastAPI 后，打开 `http://127.0.0.1:8000`。页面顶部显示服务连接状态。Swin 视觉论文是固定版本深度核查案例；QASPER train 只用于多论文方法演示，不与其 validation 问答标注或 Swin 冻结测试混用。外网论文搜索、用户上传和第二个视觉模型尚未接入。

## 操作流程

1. 在“论文筛选”输入研究问题，选择语料库，点击“检索论文”。系统通过已有混合检索／重排索引按论文来源归组；候选旁可查看命中的原文片段、路径、版本和位置。检索不调用付费生成模型。
2. 勾选需要比较的论文，点击候选标题切换当前论文。点击“从原文生成”后，系统仅向模型提供当前论文的最多 6 条已定位证据，并要求一次提交筛选建议及实验字段。页面会显示本次模型调用数和输入／输出 token；供应商未返回实际费用时不会自行估算。调用失败会在顶部显示错误，不会伪造信息卡。
3. 如果论文已有记录，可点击“读取已存卡”，不产生模型调用。查看筛选理由和九类实验字段。`原文匹配`只表示引用文字确实在当前原文片段里，不代表模型把文字分到了正确的字段。`待人工复核`、`证据不足`等状态需按其原义理解。点击“查看证据”核对段落；QASPER 显示章节／段落，Swin 显示论文页码或代码行。
4. 点击“修订筛选”可更改纳入／排除／待定及理由；点击“修订字段”可改写或清空提取项。保存会追加新记录，保留上一版本 ID，不重新调用模型。新文字若无法在所引证据中找到会标为待人工复核，而非自动支持。
5. 至少两篇已勾选论文有信息卡后，点击“生成对照报告”。报告列出字段、原文位置、逐条核查状态和可比性警告。任务、数据集、指标或输入条件缺失／不同，系统不作性能排名。可下载 Markdown；该步骤本身不调用模型。
6. “复现核查”只针对固定的 Swin 语料。输入代码或配置问题，选择结论类型并运行 Agent。程序先检索并核查结构化结论，再生成引用回答；任何证据不足应原样显示。这一步会调用付费模型。

## 接口与边界

| 接口 | 输入重点 | 产物 |
|---|---|
| `POST /v1/research/discover` | `query`, `collection`, `limit` | 按论文归组的候选及证据 |
| `POST /v1/research/auto-card` | `query`, `collection`, `source_id` | 一次模型提交、筛选记录、实验字段记录和调用量 |
| `POST /v1/research/load-card` | 同上 | 读取该论文最新筛选与字段版本，不调用模型 |
| `POST /v1/research/screening`、`/v1/research/extraction` | 原证据、人工内容、`revision_of` | 追加式修订记录，保留历史版本 |
| `POST /v1/research/compare` | 至少两条不同论文的提取 `record_ids` | Markdown 比较表、可比性标志和警告 |
| `POST /v1/agent/run` | Swin 问题与必需 Claim 类型 | 工作流阶段、逐条结论、引用回答或停止原因 |

自动信息卡保留模型动作追踪和追加式记录；旧 revision 不被覆盖。网页可人工修改决定与字段，但尚无跨版本差异比较界面。原文子串匹配无法自动验证研究语义，尤其要人工检查任务、模型、数据集、指标和结果是否正确归类。首轮真实产品 smoke 的三个模型提交失败，后续三个独立 train 样本成功；这些样本只说明功能可用，不能当作准确率或可靠性统计。参见 [P4.5 验收报告](p4-verified-workflow-report.md)。
