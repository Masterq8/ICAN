## 解释边界与助手抽查

- QASPER 官方 Answer F1 是英文参考答案与模型中文长回答的**词面**重叠；在固定问题前提下它仍是有效的可复现基准数值，但不能单独代表中文回答的语义正确率。抽查前 4 道外部题时，首题的 `labeled features`、第二题的三项正则化、第三题的文本分类场景和第四题的先验偏差解释在多组中文回答中均能找到，词面 F1 会低估这些信息。不过各回答也有冗余、范围扩大或需要逐句证据核查的内容，不能据此宣称整体语义达标。
- 助手检查了 8 道 Swin 的 Agent 答案：第 8 题正确并列冲突来源；第 2 题未完整确认第 4 stage 通道/后两层 heads，包含错误的待复核候选；第 7 题未清楚说明“拼接后 Linear 可映射为卷积权重，但 LayerNorm 使完整模块不等价”。这些是具体缺陷，不用覆盖率替代答案正确性。这是助手抽查，**不是用户或独立标注员复核**。
- QASPER 的不可回答题问“哪些现象现已被该工作覆盖”；三组把论文提到或观察到的现象当成“已覆盖”，属于范围外推。Agent 日志另有 `submit_claims` 选证据错误；工具调用错误虽然可被工作流吸收，但仍会增加成本和降低可靠性。
- Swin 位置召回只检验来源页/源码行，QASPER 完整段落召回要求引用块覆盖整段；二者都不检验每一条生成结论的语义支持。官方 Evidence F1 只对**完整覆盖**的段落提交原文，不把部分命中冒充完整段落。Agent 可多步检索，故其最终引用覆盖与 QA top-8 检索并非同等检索预算的消融。
- PaperQA2 原版与领域改造版的同条件对照**尚未进行**；本表仅比较本项目的三个工作流。P2/P3 历史结果使用其他版本与评测配置，不能并作本轮提升百分比。
