# P2.2 结构化分块实施计划

> 执行：沿用已确认的 task_plan.md 分块设计，使用 executing-plans 按任务落实；本节点完成后接 P2.3，不安装 PaperQA2 或建立向量索引。

**目标：** 将已验收的 Swin 解析单元与隔离的 QASPER 正文转换为可重建、可定位、可验证的 chunk。

**架构：** 复用 Docling 输出的结构／页级 provenance，代码按 AST 结构、配置按字段、文档按标题处理。统一 chunk 只引用 parent unit 的连续原文片段；embedding 上下文另存。QASPER 使用独立数据集和 split、章节／段落位置，不伪造页码。

**技术栈：** Python 3.11、Pydantic 2、tiktoken cl100k_base（已在本机缓存）、现有 ingestion 契约。
