# ICAN 赛事演示操作手册

- **版本：** 1.0（2026-09-25）
- **演示主路径：** 本地网页 + Swin 只读回放
- **推荐录制时长：** 4 分 50 秒

按本项目收到的赛事材料，报名及作品提交截止日期为 **2026-09-30**；提交前请核对赛事官网的最新通知。

## 1. 作品定位与演示口径

ICAN 选择**软件赛道**。作品是面向计算机视觉论文调研与复现准备的网页工作台：使用限定语料检索论文、整理实验信息卡、保留研究记录版本，并用 Agent 工具检索论文／代码证据后回答可核查问题。

录制主路径使用网页内的 **Swin 只读回放**。其组成是同一篇 Swin 论文的预置筛选／信息卡／历史快照，以及一份来自真实、已完成、非 P6 开发任务的 Agent 运行轨迹。它们是预先准备的演示数据，**不能说成刚刚在线产生的一次端到端运行结果**。Agent 轨迹可以展示真实的问题、规划轮次、工具调用顺序、工具状态、引用回答和返回的用量；每次录制都不需要重新调用模型。

回放查询聚焦一个具体边界：论文与官方代码能否说明 Patch Embedding 卷积投影后默认加入 LayerNorm 的设计动机。保存的运行回答指出：代码和配置可以支持“默认开启归一化”这一实现事实，但现有论文证据没有给出作者明确动机。这个例子适合演示系统如何展示证据与承认证据不足。

## 3. 本地只读演示：推荐录制方式

### 3.1 启动网页

只读演示不需要启动 FastAPI、不需要 `.env`、API 密钥、模型、向量索引或研究记录。第一次运行先安装前端依赖：

```powershell
cd G:\ICAN\frontend
npm install
npm run dev
```

在终端显示的本机网址打开网页。默认地址通常为 `http://127.0.0.1:5173`；如果 Vite 提示使用其他端口，以终端实际显示为准。

### 3.2 录制主流程

1. 浏览器窗口设为桌面横屏，建议 16:9、缩放 100%，关闭会遮挡内容的开发者工具和无关窗口。
2. 进入 **演示中心**，检查五阶段导航和“当前演示模式”。
3. 点击 **载入 Swin 只读回放**。页面横幅应显示“预置运行回放 · 只读”。若按钮显示“载入演示案例”，也会进入同一个本地 Swin 案例。
4. 依次使用演示中心导航跳转到 **论文筛选**、**信息卡与历史**、**Agent 工具**、**证据与结论**。导航可以跳转；历史版本和差异位于信息卡之后。
5. 在 Agent 区查看固定问题、状态、调用量、模型名、工具事件和回答。不要点击“运行核查”：回放已经包含实际历史运行，重复发起在线任务既不是回放的一部分，也可能产生费用。
6. 点击回答中的引用按钮，在右侧 **原文证据** 面板查看引文、来源路径、版本和页码／行号。可用 `[1]` 查看论文证据，用代码引用检查官方实现位置。面板展示随案例打包的证据摘录；“打开论文来源”链接会另开浏览器页面，需要网络。
7. 结束时指出证据支持的结论和未支持的动机，不要把“当前证据无法说明”改述成模型结构的已知设计原因。

进入回放后，载入、页内跳转、查看历史和打开证据面板不会发起 API 请求或模型调用，也不会写入研究记录或浏览器存储。若要在讲解后回到原工作台，可点 **退出演示**；页面会恢复进入回放前的界面状态。

### 3.3 录制前快速检查

- [ ] 网页能打开，页面没有遮挡、横向溢出或错误提示。
- [ ] 已载入只读回放，模式标签可见。
- [ ] 五个阶段的跳转都能到达对应区块。
- [ ] 历史面板显示预置版本，Agent 面板显示预置演示数据标签。
- [ ] 引用按钮能把对应内容显示到原文证据面板。
- [ ] Agent 状态、工具轨迹、回答与引用互相一致；不混说为刚刚在线执行。
- [ ] 浏览器没有显示 API 密钥、`.env`、终端私密内容或个人通知。
- [ ] 导出视频时检查 MP4 格式和总时长不超过 5 分钟。

建议以 4:50 为目标，为片头、页面跳转和结尾留少量余量。赛事没有规定视频分辨率；录制条件允许时可用 1920×1080、16:9。

## 4. 在线真实执行：可选现场补充

在线方式适合评委要求“现在提交一个任务”时演示。它与只读回放是两个明确标识的模式。在线任务是同步请求，等待期间页面只说明正在等待服务端返回；完成后才显示服务端返回的实际事件。模型工具调用可能产生费用，实际费用未返回时页面会明确显示未提供。

1. 在本机按项目环境说明恢复依赖、语料索引和模型 API 环境变量；密钥只放在本机环境变量或 `.env`，不要写进代码、录屏或提交材料。
2. 启动后端：

   ```powershell
   cd G:\ICAN
   conda activate ican
   python scripts/serve_api.py --host 127.0.0.1 --port 8000
   ```

3. 另开终端启动前端 `npm run dev`，并确认 API 已按项目配置由 Vite 转发。
4. 不处于只读回放时，在 Agent 输入区使用已准备的开发问题，检查范围和预算后再点击 **运行核查**。不使用 P6 冻结题，也不为录制反复运行同一问题。
5. 任务结束后展示返回的实际工具顺序、状态、回答和证据。若返回证据不足、工具失败或没有详细轨迹，如实展示该状态。

在线模式的详细环境恢复方法见 [环境说明](environment-setup.md) 和 [P5 网页使用说明](p5-web-guide.md)。本机在线运行通过不代表已完成公网部署；竞赛要求的稳定可访问网页链接仍需单独准备。

## 5. 录制中的表达规则与常见问题

- 用“预置演示数据／真实开发运行回放”介绍 Agent 轨迹；用“当前在线执行结果”介绍刚提交的在线任务。
- 预置筛选和信息卡、预置历史、预置报告快照与 Agent 轨迹在演示页面组成一条同论文讲解线；它们不是一个刚刚同步生成的在线任务产物。
- 讲解“证据支持”“待复核”“证据不足”等状态时照页面显示，不推断额外结论。
- 不展示 planner 隐藏内容、原始工具输出、API 密钥或费用猜测；页面只展示经过安全投影的轨迹摘要。
- 若服务未启动或 API 不可用，回到本地只读回放继续讲解；不要自动重复可能计费的请求。
- 若评委询问抽取可靠性，说明自动抽取质量门尚未通过，字段需要人工核对；不要把开发结果包装成全面自动化。
- 若评委询问商业价值，可讲目标用户和预期工作流；目前没有已验证的商业收入、用户规模或效率提升数据。

## 6. 正式提交前仍需完成

1. 完成不超过 20 页的应用方案 PDF，并把项目原创贡献、第三方项目／数据来源、许可证、授权和素材署名写清楚。
2. 按第五节录制并检查 MP4，最终时长不超过 5 分钟。
3. 准备评委可直接访问的稳定在线网址，或随报名材料提供完整可运行程序和启动说明。
4. 完成源代码说明和比赛现场应急本地版本；断网时按第三节运行静态演示。
