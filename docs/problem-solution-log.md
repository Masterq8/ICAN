# 问题与解决方案日志

> 用途：记录产品、数据、算法、工程和交付过程中出现的问题，保留尝试、证据和最终方案，避免重复踩坑。

## 使用规则

1. 每个问题使用唯一编号：`P-YYYYMMDD-NN`。
2. 问题出现时立即登记；暂时无解时状态设为“调查中”。
3. 方案必须包含验证方法，不能只记录“已修复”。
4. 新证据推翻旧结论时保留历史，在“后续更新”中说明变化。
5. 涉及产品范围变化时，同步更新需求文档与开发路线图。

## 状态定义

- `待处理`：已确认问题，尚未开始。
- `调查中`：正在定位原因或比较方案。
- `已解决`：方案已实施并通过验证。
- `已接受`：短期不处理，已记录影响和理由。

### P-20260915-01：首版范围过大

- **现象：** 同时实现开放网络论文搜索、系统综述、任意仓库执行和完整论文复现，无法在截止前可靠交付。
- **原因：** 用户流程包含多个高不确定性子系统。
- **解决方案：** 比赛版使用精选计算机视觉语料库；完整支持论文筛选、提取、比较和报告，深度复现核查先覆盖 Swin-T 与 Vision Mamba。
- **验证：** 每个开发节点均能独立演示，P6 前完成端到端串联。
- **状态：** 已解决。

### P-20260915-02：RAG 与 Agent 职责不清

- **现象：** 容易把“用了向量库”或“调用了大模型”统称为 Agent。
- **解决方案：** RAG 负责召回和提供证据；Agent 负责规划、工具选择、证据充分性判断、补查和终止。
- **验证：** 日志能够分别展示检索结果和 Agent 状态迁移；评测分别报告检索质量与任务完成质量。
- **状态：** 已解决。

### P-20260915-03：纯向量检索遗漏精确字段

- **现象：** `DROP_PATH_RATE`、文件名和参数值等标识符不一定具有稳定的语义向量表示。
- **候选方案：** 向量检索；BM25；二者经 RRF 融合后重排序。
- **当前方案：** P2 先建立向量基线，P3 使用同一测试集对比混合检索。
- **完成标准：** 记录 Recall@5、MRR、延迟和索引成本，以实测决定默认方案。
- **状态：** 待验证。

### P-20260915-04：无证据时生成答案

- **风险：** 报告看似完整但引用不能支持结论。
- **解决方案：** 生成前设置最低证据条件；生成后逐条执行引用支持检查；不满足条件时输出“证据不足”和建议补查项。
- **完成标准：** 无答案测试集中，系统不支持结论率达到项目验收目标。
- **状态：** 待验证。

### P-20260915-05：配置覆盖导致误判

- **现象：** Swin-T 默认配置、专用 YAML、命令行和运行时代码共同决定最终值。

- **验证：** 对人工标注的配置链逐项核对最终值和来源。

### P-20260915-17：Ragas 与 LangChain/OpenAI SDK 的隐式版本冲突

- **现象：** `pip check` 报告无冲突，但导入 Ragas 失败：`langchain_community.chat_models.vertexai` 不存在。

- **已尝试方案：** 首次只升级 Ragas/OpenAI 相关包，Ragas 仍因 LangChain Community 0.4 的模块删除而失败。
- **最终方案：** 固定 `ragas==0.4.3`、`instructor==1.17.0`、`langchain-community==0.3.31`、`langchain-openai==1.1.9` 和 OpenAI SDK 2.x；完整版本写入锁文件。
- **验证结果：** Ragas 导入成功，`pip check` 无冲突；核心模块导入与全部环境冒烟测试通过。
- **关联文件或节点：** `requirements/ican.txt`、`requirements/ican-lock.txt`、`scripts/smoke_environment.py`、P2。
- **状态：** 已解决。

### P-20260915-18：Conda 元数据请求瞬时 SSL EOF

- **现象：** 创建环境时读取仓库元数据出现一次 `SSLEOFError: UNEXPECTED_EOF_WHILE_READING`。
- **原因分析：** 远端连接在 TLS 响应结束前中断，属于瞬时网络问题，未发现本机证书配置持续异常。
- **解决方案：** 保留 Conda 的自动重试，不关闭 SSL 校验；重试后环境创建成功。
- **验证结果：** Python 3.11.16 环境完整创建，后续包下载和索引访问正常。
- **状态：** 已解决。

### P-20260915-19：版本约束被 PowerShell/.bat 解析为重定向

- **现象：** 将 `openai>=2,<3` 经 `conda.bat run` 传入时，命令报告找不到文件，并在项目根目录留下空文件 `2`。

- **验证结果：** 同一约束的 dry-run 与正式安装均成功，项目根目录已确认不存在空文件 `2`。
- **状态：** 已解决。

### P-20260916-03：PyMuPDF 将左右栏文本合并为跨栏块

- **分类：** 解析。
- **现象：** 双栏 PDF 测试读出 LEFT ONE、RIGHT ONE、LEFT TWO、RIGHT TWO；块排序不能纠正块内混栏。

- **验证结果：** 原始 PDF 块输出确认合并原因；双栏回归测试通过。
- **状态：** 已解决；复杂图表仍需视觉核查。

### P-20260916-07：QASPER 标注中有无法映射到正文的证据
