# 开发主线与节点交付

## 1. 项目目标

在 2026 年 9 月 30 日前完成一个可在线演示的软件作品：用户能够筛选计算机视觉论文、提取和比较实验信息、获得带引用研究报告，并对选定论文与官方代码执行复现准备核查。

## 2. 主线原则

- 每个节点都必须产生可运行、可查看或可测量的产物。
- 优先完成一条窄而完整的链路，再增加论文与工具数量。
- 新想法先收集、后评估，不直接插入正在进行的节点。
- 每次范围调整都记录原因、影响的节点和被推迟的工作。
- 指标和案例使用真实运行结果，文档中不预填虚构提升数字。

## 4. 各节点详细交付

### M1：数据与标准答案

- `data/catalog/papers.json`：论文元数据、版本、任务、代码链接。
- `data/raw/`：固定版本的论文与仓库材料。
- `docs/swin-t-evaluation-methodology.md`：社区问题调研、纳入规则、证据标准、配额和冻结方法。
- `data/eval/swin_dev.jsonl`：开发问题与标注证据。
- `data/eval/swin_test.jsonl`：冻结测试问题。
- `docs/corpus-manifest.md`：来源、commit、许可、采集时间。

开发集与冻结测试集按问题簇划分为 12/8。同义问题、同一帖子拆分问题和相同证据闭包不得跨集合。

**M1 验收记录（2026-09-15）：** 已完成 31 条社区候选来源、27 个证据 ID、12 个开发题、8 个冻结测试题及 SHA-256 manifest；JSON/JSONL、证据引用、配额和泄漏分组检查通过。

### M2：基础 RAG

- PDF 章节与页码保留；代码按文件、函数、配置块分块。
- 文档块统一带 `source_id`、`source_type`、`page/path/line`、`version` 元数据。
- API 至少提供建库、检索和问答三个入口。
- 回答中的每条关键结论返回 `citation_ids`。

**P2.2 验收记录（2026-09-16）：** 已复用 Docling 解析结构，交付连续原文分块、独立上下文、配置与重建／验收脚本；Swin 1,602块、QASPER 2,357块。60项测试通过，1项真实符号链接测试因系统权限跳过，模拟链接与实际硬链接回归通过。12个产物重建哈希一致，11个输入／eval文件未变。详见 [分块使用说明](p2-chunking-guide.md)。下一节点P2.3实际Embedding tokenizer核验与Qdrant索引；尚未完成检索问答。

### M3：混合检索与评测

**P3完成更新（2026-09-18）：** 已实现范围预过滤、BM25／dense的RRF融合、本地固定重排及原始配置／代码结构补充。完成282条最终检索、47次同adapter回答和47份新审核；dev Top8定位召回80.56%／dense32.64%，完整行范围31.94%／8.33%，固定答案点40/49／18/49。QASPER召回及答案F1下降，默认dense保留，不观察validation后调参。具名字段边界和短查询YAML丢失均补回归；修复前后47题实际PaperQA2输入一致，未追加生成。下一P4优先数值工具、跨stage补查、配置分支／实验归因，开始规划前提醒使用最高阶模型。见[P3报告](p3-retrieval-report.md)及[使用说明](p3-retrieval-guide.md)。

**P2.6完成（2026-09-17）：** 用户授权助手选择94次双版对照；47题dense检索、94次真实生成及94份助手审核完成。QASPER validation答案F1领域版16.95%／默认版8.42%，Swin评分点覆盖18/49／16/49；助手审核与词面评分分开。无服务错误，费用按高峰cache-miss价格估算0.0779415美元，实付未知。基线检索未调参，模型变体混入、入口与配置链缺证据、拒答标记漏识别作为P3优先事项，详见[基线报告](p2-baseline-report.md)。

**P2.5验收记录（2026-09-17）：** 固定PaperQA2 2026.8.12公开对象与aquery接入，带引用API、原始输出校验及单次DeepSeek调用完成。真实配置／论文样例分别定位YAML第6–9行与PDF第2／4页，保留首轮失败及prompt v1→v2记录。123测试通过／1Windows权限跳过，独立审查确认引用漏洞修复。下一节点P2.6基线；自主Agent在P4，网页在P5。详见[问答说明](p2-qa-guide.md)。

**P2.3验收记录（2026-09-17）：** 固定BGE-M3快照、真实tokenizer、float16编码和1024维Cosine向量。3959点进入3个Qdrant持久化collection；独立进程逐点与实际tokenizer检查通过，79测试通过／1系统权限跳过，61原输入／eval未变。下一节点P2.4接口及来源约束；中文smoke配置查询暴露近似变体召回，纳入问题日志与P3精确字段检索验证。详见 [索引说明](p2-indexing-guide.md)。

**P2.4验收记录（2026-09-17）：** 完成FastAPI只读证据接口，支持collection、来源类型和安全路径前缀，返回chunk、固定版本、页码／行号和分数。真实HTTP验证显示标准Swin配置目录约束可排除SwinV2／SwinMoE路径混入；不把此功能结果表述为答案正确率。下一节点为P2.5 PaperQA2接入与带引用问答；进入Agent规划或回答生成前先切换最高阶模型。详见[检索接口说明](p2-retrieval-guide.md)。

- 稠密向量用于语义和中英文表达匹配。
- BM25 用于参数、路径、缩写和精确值。
- RRF 或同类方法融合候选，重排序模型选择最终上下文。
- 固定同一问题集对比 dense、BM25、hybrid、hybrid + rerank。

### M4：Agent 复现核查

**P4.1–P4.2实现更新（2026-09-18）：** 实际扩展固定PaperQAEnvironment／Aviary工具执行、状态历史与Docs.aquery；Pro通过原生OpenAI tool calls规划，Flash回答。已接入`POST /v1/agent/run`，提供scoped检索、原块读取、静态配置链与Decimal算术。每任务5次规划／12工具／1回答，首轮累计40付费预约；同参工具缓存，预算和超时明确停止。筛选、结构化抽取、核查表及多论文报告尚属P4.3，扩展开发／外部评测属P4.4。见[使用说明](p4-agent-guide.md)与[实际验收报告](p4-agent-report.md)。

以P2.5验证后的PaperQA2为主要问答／Agent复用目标，增加领域证据与工具adapter；LangGraph只在需要时管理筛选、抽取、核查、报告的外层业务状态。

Agent 节点：理解任务、形成核查计划、检索证据、判断充分性、调用工具补查、生成核查项、校验引用、生成报告。

本节点实际工具：

1. `search_evidence`：在固定collection、家族、路径和类型内检索。
2. `read_evidence`：按原chunk ID或精确函数结构读取已入库材料。
3. `trace_config`：静态追踪精确默认字段、BASE／YAML、结构化opts及部分CLI；不执行仓库。
4. `calculate`：有界标量加减乘除、整数幂、整数整除及取模，不运行Python代码。
5. `gen_answer`：一次PaperQA2证据回答，工具产物与引用原文分开。
6. `complete`：依据真实回答状态结束。

精选论文元数据筛选及多论文业务工具在P4.3扩展，不将现有全文检索称为完整论文筛选流程。

安全与停止条件：限制最大循环次数、单次读取量、总 token 和失败重试次数；没有足够证据时返回待确认。

### M5：网页体验

核心页面：

1. 论文库与筛选页。
2. 论文详情及结构化实验卡。
3. 多论文比较与研究报告页。
4. 复现核查任务页。
5. Agent 执行轨迹与证据详情页。

### M6：评测

- 检索：Recall@5、MRR、命中来源类型、延迟。
- 生成：答案正确率、引用支持率、无答案识别率。
- Agent：工具选择准确率、核查项完成率、平均步数、失败恢复率。
- 系统：端到端耗时、模型调用量、估算成本、稳定性。

## 5. 变更机制

### 想法进入流程

`想法收件箱 → 价值/成本评估 → 进入当前版本、下个版本或放弃 → 更新需求和节点`

评估维度：比赛得分价值、求职展示价值、用户价值、开发工时、技术风险、对当前节点的影响。

- 今天完成的交付物能否独立演示或验证？
- 是否新增了问题、风险或待确认假设？
- 是否需要调整后续节点，而不是悄悄扩大当前节点？
- 是否保留了真实测试结果、失败案例和版本信息？
- 离比赛提交还剩多少缓冲时间？
