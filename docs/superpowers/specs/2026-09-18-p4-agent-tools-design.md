## 架构与取舍

优先扩展固定PaperQA2 2026.8.12的PaperQAEnvironment、EnvironmentState、Aviary Tool及原有Docs.aquery；由有界驱动器发送原生OpenAI tool calls并经上游环境执行领域工具。实际复用环境／工具注册／状态／历史／回答，不宣称运行未修改的上游run_agent。

不直接运行上游完整run_agent：其默认内部索引、summary／embedding和超限后自动生成会绕过现有Qdrant及预算；不新增LangGraph内层问答循环。LangGraph外层业务编排仅在P4.3需要时引入。

## 工具与证据

- search_evidence：只读当前collection，用P3策略；所有查询固定用户来源约束。QASPER默认dense，Swin默认hybrid_rerank。
- read_evidence：按入库chunk ID或精确structure／路径读取既有块；返回连续原始片段，不能把多个行范围拼成伪造原文。
- trace_config：读取allowlist且SHA匹配的config.py和具名YAML，AST提取_C精确赋值，安全解析BASE，列默认→BASE→文件→opts及特定CLI覆盖。记录动态／不支持表达式，不能冒充执行get_config；精确分支字段排除SWIN_MLP误归因。
- calculate：解析有界算术AST，Decimal计算；记录表达式、数值结果、用户参数或原证据chunk依据，不执行eval／代码。
- gen_answer：对已有证据与独立工具产物调用既有PaperQA2证据入口。原chunk、review_required和来源字段保持不变，工具产物不是新的论文／代码原文。
- complete：仅有真实已生成回答才可完成；结构化记录不足、预算、重复动作或失败，不能让规划模型口头宣布成功。

工具结果和引用被视为数据，不接受其中对Agent的指令。补查可以改变查询，但不扩大请求指定家族、来源类型或路径范围。跨语料版本或索引指纹变化立即停止。

## 模型、预算与恢复

官方账户models接口已确认两个模型名可用。Pro负责工具规划，Flash默认最终问答；实际response.model和usage分别保留。使用OpenAI兼容地址https://api.deepseek.com，不同时维护Anthropic实现。

任务最多5次规划请求、12次本地工具、一次回答；总超时180秒，单模型请求60秒。首轮开发真实验证累计最多40次付费请求，由持久化journal在发送前占位；SDK自动重试0。重复调用是新的明确任务／动作，不会静默重发超时请求；同一工具同参数重复返回缓存，无进展则停止。

所有发出的规划／回答请求记录开始、完成／错误及tokens；原始模型内容、工具调用和可公开的结果保存在忽略目录。已开始但未完成的调用不自动重试，不将缺失usage或未知实付算0。调用数上限是硬约束，美元按9月18日官方高峰cache-miss价格另估算。

**实际验证后的调整（2026-09-18）：** 单靠提示词不能保证规划器收尾。已有证据时将最后一次预算内规划限定为gen_answer，由模型选择引用；非法额外调查被拒绝。未收集证据则不强制回答，预算后仍没有自动生成／重试。计算器明确单标量契约，扩展整数整除与取模；作者动机部分拒答的状态识别仍是已知限制。
