# ICAN 真实后端演示视频设计

## 目标

为 ICAN 挑战赛制作一份不超过 5 分钟的正式视频讲解稿。视频以真实启动的 FastAPI 后端为基础，通过两次在线任务串起论文检索、实验信息卡、Agent 规划与工具调用、证据回查和历史记录，不使用只读回放冒充在线执行。

## 成片与母版

- 录制一份包含完整模型等待时间的连续母版。
- 参赛成片目标时长为 4 分 45 秒，最大不得超过 5 分钟。
- 成片只压缩无交互等待，并显示“真实在线执行 · 等待过程已压缩”。
- 同一结果的请求画面、任务状态、用量、答案和引用必须来自同一次运行。
- 失败、待复核、证据不足和前置条件阻断均按页面真实状态呈现。

## 演示主线

### 在线任务一：论文筛选与实验信息卡

检索问题：

> 梳理 Swin Transformer 的层级架构、Patch Merging、训练数据集、评价指标和主要实验结果，并保留论文原文证据。

操作范围限定为 `swin_v1`。用户在线检索候选论文，选择固定 Swin Transformer 原论文，并点击“从原文生成”。页面返回真实阶段状态、模型用量、筛选决定、实验字段和证据位置。操作者打开一条数据集或结果字段的证据，并展示该论文的研究记录历史。

### 在线任务二：Agent 代码核查

Agent 问题：

> 在固定官方 Swin-T 的 `PatchMerging.forward` 中，给定 `H=8`、`W=8`、`L=64`，长度和奇偶性前置条件是否通过？四路切片拼接后通道维度如何变化？请引用官方源码说明，不能把静态核查说成实际训练运行。

核查类型选择“代码前置条件”。页面应展示实际返回的规划／工具轨迹、调用量、停止原因、结论状态、答案和源码引用。预期核查重点是 `L == H × W`、`H/W` 为偶数、四路切片拼接为 `4C`，以及后续 `Linear(4C, 2C)`；最终讲解必须服从实际返回，不在结果产生前预设成功。

## 表述边界

- “原文匹配”只表示引文能定位到来源，不等于字段语义自动正确。
- 信息卡自动输出是模型建议与确定性校验结果，仍保留人工复核入口。
- Agent 的代码前置条件检查是静态核查，不等于运行训练代码或完成模型复现。
- 页面显示的模型、调用次数、token、停止原因和费用状态按实际内容朗读，不预填数字。
- 不宣称节省固定比例时间、行业首创、自动替代研究者或自动保证答案正确。
- 不展示 `.env`、API Key、Cloudflare Tunnel Token、评测答案或内部原始规划文本。

## 结果分支

### 信息卡完成

说明系统完成了证据准备、模型提交、结果校验和记录保存，再选择一条字段回查来源。

### 信息卡待复核

说明模型已经返回候选内容，但确定性检查发现需要研究者确认的字段；展示论文内搜索、证据查看或人工修订入口，不将其描述为自动成功。

### Agent 完成或需要复核

按页面逐条解释实际工具轨迹和引用结论。如果结论需要复核，强调系统将推断与直接事实分开。

### Agent 前置条件阻断或证据不足

将其作为可信终态展示：系统没有继续假定后续代码可执行，也没有利用常识补写缺失证据。

### 在线请求失败

保留失败母版。若重新录制，必须重新录制完整请求和对应结果；不得把旧请求与新答案剪成同一次任务。

## 验收标准

- 视频包含两个明确的在线提交动作和两个真实返回结果。
- Agent 过程至少展示接收请求、工具选择、工具结果、停止状态和有引用回答。
- 至少打开一条论文证据和一条官方源码证据。
- 成片中的等待压缩均有字幕提示。
- 成片不超过 5 分钟，推荐落在 4 分 40 秒至 4 分 50 秒。
- 讲解词提供正常结果、待复核和失败三类现场替换话术。
- 旧的只读演示稿继续保留为无后端时的备用方案。
