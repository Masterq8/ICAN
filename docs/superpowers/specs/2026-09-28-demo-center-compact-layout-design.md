# 演示中心紧凑布局设计

## 目标

删除演示中心内重复的流程介绍段落和底部录制提示，将剩余元素重新排布为紧凑、均衡且适合录屏的三层结构。

## 布局

1. 顶部标题栏保留英文眉题、主标题、当前模式和收起按钮。
2. 标题栏下方放置横跨卡片的深色模式操作条：模式说明位于左侧，回放按钮与 Agent 链接位于右侧。
3. 五阶段导航直接作为卡片底部内容，保持原有链接、时间、标题和说明。

## 删除内容

- 删除“从提出问题、筛选论文到 Agent 工具调用与证据回查……”介绍段落。
- 删除包含“展示顺序可跳转……”和“录制建议……”的整个底部提示栏。

## 约束

- 不改变回放加载、Agent 锚点跳转、折叠控制、忙碌状态和只读构建行为。
- 桌面端操作条采用左右布局；900px 以下自动堆叠。
- 不增加新的业务状态、存储或 API 请求。
