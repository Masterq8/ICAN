# P5 主要功能卡片展开与收起设计

## 背景与目标

当前研究工作台采用纵向长页面展示完整演示流程。Swin 只读案例加载后，实验信息卡、版本差异、研究报告和 Agent 轨迹内容较长，用户需要频繁滚动才能查看后续模块。

本功能为七个主要功能卡片增加独立的展开／收起控制：演示中心、论文筛选、实验信息卡、历史版本、对照报告、复现核查和原文证据。默认全部展开；用户收起卡片后仍可识别其编号、标题和当前状态。

## 交互范围

- 每个主要卡片的标题区右侧增加带文字和箭头图标的按钮。
- 展开状态显示“收起”，收起状态显示“展开”。
- 收起后保留卡片外框和标题区，隐藏其余正文。
- 每张卡片独立控制，不增加“全部展开／全部收起”。
- 候选论文、信息卡字段、历史差异行、Agent 事件和引用等内部条目不增加折叠按钮。
- 公网只读演示与本地在线模式使用同一交互。

## 状态与数据边界

在 `App.vue` 中维护七个稳定 section key 的展开状态，初始值均为展开。切换只改变可见性，不清除查询、候选论文、信息卡、版本选择、报告、Agent 结果或当前证据。

正文使用 `v-show` 隐藏，使表单值和组件内部状态在重新展开后保持不变。折叠状态只存在于当前页面内存中；刷新页面恢复默认展开，不写 `localStorage`，也不触发 `/v1` 请求。

`DemoCenter.vue` 通过 `collapsed` prop 和 `toggle-collapse` 事件接入父级状态。其余主卡片由 `App.vue` 直接包裹正文。按钮样式统一复用一个轻量 `PanelCollapseButton.vue` 组件，避免七处重复图标、文案和无障碍属性。

## 无障碍与导航

- 按钮设置 `aria-expanded` 和 `aria-controls`，正文容器具有稳定 ID。
- 按钮可通过键盘操作，文字不会只依赖箭头方向表达状态。
- 侧边导航锚点仍定位到卡片标题；卡片处于收起状态时不会自动展开。
- 标题和现有业务操作按钮保持原有顺序，折叠按钮位于操作区末尾。

## 视觉规则

- 使用现有 `text-button` 视觉语言，配合 `ChevronUp`／`ChevronDown`。
- 收起卡片减少底部留白，但保留与相邻卡片一致的圆角、边框和间距。
- 证据面板收起后仍保留“原文证据／当前选中来源”标题；现有“关闭证据”只负责清空所选证据，与收起功能分开。
- 窄屏时按钮保持可点击尺寸，标题区允许换行，不覆盖业务操作。

## 测试与验收

1. 单元测试覆盖默认展开、单卡收起、重新展开和各卡状态互不影响。
2. 验证收起再展开后，信息卡、历史版本选择、Agent 轨迹及证据仍保留。
3. 验证按钮文案、图标、`aria-expanded` 与正文可见性同步。
4. 运行前端 Vitest、TypeScript 检查和生产构建。
5. 在浏览器分别检查桌面与窄屏布局，确认七张主要卡片均可独立展开／收起，且只读演示过程中没有新增 `/v1` 请求。

## 范围边界

本节点只增加主要卡片的本地可见性控制，不重排页面、不修改业务数据、不保存折叠偏好、不折叠内部明细，也不改变只读演示和在线 API 的行为。
