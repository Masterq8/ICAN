# P2.5 PaperQA2 Implementation Plan

> **For agentic workers:** Use executing-plans in the current session. User has approved the design and selected continuous inline execution; no additional execution-choice gate is needed.

**Goal:** Actually reuse fixed PaperQA2 for single-call answers with source-locatable citations from the existing verified retrieval service.

**Architecture:** Existing EvidenceSearchService → domain Doc/Text/Context adapter → Docs.aquery → raw citation validator → QA response. LLM runtime is explicitly configured and has no implicit credential/model fallback.

**Tech Stack:** Python3.11, paper-qa2026.8.12, fhlmi1.0.7, LiteLLM1.84.1, FastAPI, existing BGE-M3/Qdrant.
